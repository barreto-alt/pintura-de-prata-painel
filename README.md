# Pintura de Prata — Painel financeiro

Painel com o resultado mensal da oficina, as contas a pagar em atraso e a planilha de dívidas.

- **Resultado do mês:** faturado, margem de contribuição, gasto com peças e ticket médio por seguradora/particular.
- **Contas em atraso:** boletos vencidos de fornecedores, com destaque para os que estão em cartório.
- **Dívidas:** atrasos, parcelas mês a mês e saldo de bancos, tributos, pessoal e Frezza.

Abra `index.html` no navegador. Os dados estão dentro do próprio arquivo.
Para publicar como site, ative o GitHub Pages em *Settings → Pages → Deploy from a branch → main / (root)*.
